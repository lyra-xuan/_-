# Background Music Credits

The background music tracks in this directory were transcoded from the
user-provided `Touhou Lossless` music pack (`E:\My Game_2\H\Touhou Lossless`).
Each FLAC source was converted to a mono/stereo 128 kbps Vorbis OGG with
`ffmpeg -c:a libvorbis -b:a 128k -ar 44100`, and each file was renamed to
describe the scene it plays in.

| File | Scene | Original track | Source album |
|---|---|---|---|
| `title.ogg` | 标题页 | 二色蓮花蝶 ～ Ancients | 秋霜玉 ～ Shuusou Gyoku |
| `stage.ogg` | 关卡战 | 少女綺想曲 ～ Capriccio | 東方幻想郷 ～ Lotus Land Story (TH04) |
| `boss.ogg` | Boss 符卡战 | 魔女達の舞踏会 ～ Magus | 秋霜玉 ～ Shuusou Gyoku |
| `ending.ogg` | 胜利后记与鸣谢 | Peaceful Romancer | 東方怪綺談 ～ Mystic Square (FM86) |

All tracks were composed by ZUN. 東方幻想郷 is part of the Touhou Project
(© Team Shanghai Alice / ZUN); 秋霜玉 is a Seihou Project title with music by
ZUN. The user confirmed that the provided material is licensed for use in this
project. Only lossy OGG copies are kept in this repository, not the original
lossless files.
