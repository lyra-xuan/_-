# 功能需求与验收范围

## 项目目标

制作一款突出碰撞检测原理的单人 2D 弹幕射击游戏。使用 Python + pygame-ce，不依赖游戏引擎。运行效果要直观，便于演示命中区、擦弹区和扫掠检测。

## 当前已具备

- 玩家基础移动、低速移动、暂停和退出。
- Z 点按单发、按住连续射击，火力随道具成长（1.00 单发 / 2.00 双发 / 4.00 四发）；Boss 横向移动。
- 三段符卡：阶段 1 五发瞄准扇形、阶段 2 大玉环 + 交错小玉双层环形、阶段 3 六臂旋转螺旋外加散射。
- 符卡限时：每阶段 45 秒，倒计时归零强制推进阶段（阶段 3 超时视为击破）。
- 掉落道具：红玉 POWER（火力 +0.05，满火力折算分数）、青玉 POINT（+500）、绿玉 LIFE（残机 +1）；进入自机吸附范围后被磁吸。
- Boss 血条、符卡条（符卡名 / 剩余段数 / 倒计时）、玩家生命数、火力值与道具计数、得分与命中/擦弹/敌弹计数。
- 计分与最高分持久化：擦弹 +500、过阶段 +5000、击破 +10000；最高分写入 `hiscore.txt`。
- 玩家有 3 条命；受击后重生、清除当前敌弹并获得 1.5 秒无敌时间。
- F3 可切换作弊无敌模式；状态在 HUD 明示，再按 F3 关闭。
- Boss 击破后依次展示战绩、东方口吻后记与鸣谢三页，可翻阅；胜利结算使用原作结局图与 Staff Roll 图，并循环播放《Peaceful Romancer》。生命耗尽后可重新开始或返回标题页。
- 弹幕场三层渲染与暗角；自机按移动方向切换动画帧组，低速时显示判定点。
- 命中火花、擦弹星环、受击与击破大爆等特效；Boss 立绘随阶段切换并受击闪白。
- 飘落的小妖精使用两组原作动画，可被击破并轮换掉落 POINT / POWER，稀有掉落 LIFE。
- 音效覆盖发射、命中、擦弹、警报、死亡、阶段切换与菜单操作；背景音乐按场景循环切换；无音频设备时静默降级。
- AABB、圆-圆、线段-圆几何函数及空间网格。
- 玩家/敌弹、玩家弹/Boss 相对运动扫掠碰撞。
- 标题菜单与说明书：背景说明 / 用语解说 / 操作指南三页，哥特描金边框与绯红页签，←/→ 翻页，以及开始/退出流程。用语解说收录幻想乡、博丽的巫女、红魔馆、符卡、红符/红魔法/神枪、弹幕、自机、残机、判定点、擦弹与三种道具等世界观与玩法术语。
- 标题、开战、暂停与胜败结算均有独立过场卡片；胜利后支持战绩、后记、鸣谢三页，使用原作结局图和 Staff Roll 图；失败结算可返回标题。
- 自动化测试覆盖输入、场景切换、说明书翻页、实体、战斗、道具、贴图、音效与背景音乐降级行为。

## 已确认规模与 V1 状态

已确认采用**一关一 Boss**的短流程，视觉方向参考东方幻想弹幕游戏。标题和战斗画面使用用户提供并确认许可的图片素材；碰撞检测逻辑独立于图片渲染。

V1 功能进度：

1. [已完成] 标题页：开始、说明书、退出。
2. [已完成] 单个可操作角色：移动、低速、点按单发/按住连发，火力随道具成长。
3. [已完成] 一个 Boss：三段符卡与阶段切换，并带符卡限时。
4. [已完成] 命中、擦弹、生命与无敌反馈；擦弹/过阶段/击破计分与最高分持久化。
5. [已完成] 胜利结算、后记与鸣谢三页（原作结局/Staff Roll 插图），胜利后可翻阅并播放专用结局曲；失败可重开或返回标题。
6. [已完成] 碰撞调试演示：F2 切换调试层，显示空间网格、命中/擦弹判定圆、敌弹扫掠线段与当帧候选/命中统计。
7. [已完成] 美术与音效强化：东方红魔乡背景/自机/Boss/弹幕/特效素材、可击破小妖精、10 个音效与三首循环背景音乐。
8. [已完成] 说明书页：东方口吻的背景说明、世界观用语解说与操作指南三页，哥特描金边框与绯红页签。

控制在一关和一个 Boss，不扩展多角色、多关卡或复杂剧情。东方作品的角色、立绘、音乐和游戏内图像素材仅在许可覆盖本项目使用时引入；标题、战斗图片、音效与背景音乐的来源及许可分别登记在 `assets/title/ATTRIBUTION.md`、`assets/gameplay/ATTRIBUTION.md`、`assets/audio/ATTRIBUTION.md` 与 `assets/bgm/ATTRIBUTION.md`。

## 验收标准

- 可从标题页开始游戏，并能正常暂停、胜利/失败与重开；胜利后可阅读战绩、后记和鸣谢，失败后可返回标题页。
- 玩家命中扣除一条命，无敌期间不会重复受击；生命耗尽后战斗停止。
- 玩家和 Boss 均能按窗口边界移动，操作响应稳定。
- 至少三段符卡弹幕可观察到，并产生可复现的命中与擦弹。
- 道具可被射击或吸附拾取，火力 / 得分 / 残机按配置生效，火力封顶后折算为分数。
- 说明书三页可翻页并返回标题页，背景说明、用语解说与操作指南内容完整。
- 擦弹只对每颗子弹计分一次；命中与擦弹不会混为一类。
- 擦弹、过阶段、击破均按配置加分，得分超过历史最高分时写入 `hiscore.txt`。
- 弹幕场与右侧栏使用素材绘制，音效/背景音乐缺失或音频设备不可用时游戏仍可正常运行。
- 高速移动和玩家移动时，扫掠碰撞能检测相对运动，不因单帧跨越漏判。
- 几何边界、相切、静止线段和网格边缘有自动化测试。
- 可在 Python 3.12 + pygame-ce 环境运行；不使用游戏引擎。

## 暂不纳入

联网、存档、排行榜、多个可玩角色、多关卡、复杂剧情、完整弹幕脚本编辑器和大量素材动画。若课程要求有变化，再调整范围。
