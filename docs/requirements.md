# 功能需求与验收范围

## 项目目标

制作一款突出碰撞检测原理的单人 2D 弹幕射击游戏。使用 Python + pygame-ce，不依赖游戏引擎。运行效果要直观，便于演示命中区、擦弹区和扫掠检测。

## 当前已具备

- 玩家基础移动、低速移动、暂停和退出。
- Z 点按单发、按住连续射击；Boss 横向移动，半血切换五发瞄准扇形与八方向环形弹幕。
- Boss 血条、阶段提示、玩家生命数与命中/擦弹计数。
- 玩家有 3 条命；受击后重生、清除当前敌弹并获得 1.5 秒无敌时间。
- Boss 击破后的胜利提示与重新开始；生命耗尽后可重新开始或返回标题页。
- AABB、圆-圆、线段-圆几何函数及空间网格。
- 玩家/敌弹、玩家弹/Boss 相对运动扫掠碰撞。
- 标题菜单、操作说明页和开始/退出流程。
- 自动化测试覆盖输入、场景切换、实体、战斗与碰撞行为。

## 已确认规模与 V1 状态

已确认采用**一关一 Boss**的短流程，视觉方向参考东方幻想弹幕游戏。标题和战斗画面使用用户提供并确认许可的图片素材；碰撞检测逻辑独立于图片渲染。

V1 功能进度：

1. [已完成] 标题页：开始、操作说明、退出。
2. [已完成] 单个可操作角色：移动、低速、点按单发/按住连发。
3. [已完成] 一个 Boss：两种弹幕模式与半血阶段切换。
4. [部分完成] 命中、擦弹、生命与无敌反馈已具备；分数系统待制作。
5. [已完成] 胜利、失败、重新开始及失败后返回标题页均已具备。
6. [已完成] 碰撞调试演示：F2 切换调试层，显示空间网格、命中/擦弹判定圆、敌弹扫掠线段与当帧候选/命中统计。

控制在一关和一个 Boss，不扩展多角色、多关卡、道具或复杂剧情。东方作品的角色、立绘、音乐和游戏内图像素材仅在许可覆盖本项目使用时引入；标题和战斗图片的来源及许可分别登记在 `assets/title/ATTRIBUTION.md` 与 `assets/gameplay/ATTRIBUTION.md`。

## 验收标准

- 可从标题页开始游戏，并能正常暂停、胜利/失败、重开；失败后可返回标题页。
- 玩家命中扣除一条命，无敌期间不会重复受击；生命耗尽后战斗停止。
- 玩家和 Boss 均能按窗口边界移动，操作响应稳定。
- 至少两种弹幕模式可观察到，并产生可复现的命中与擦弹。
- 擦弹只对每颗子弹计分一次；命中与擦弹不会混为一类。
- 高速移动和玩家移动时，扫掠碰撞能检测相对运动，不因单帧跨越漏判。
- 几何边界、相切、静止线段和网格边缘有自动化测试。
- 可在 Python 3.12 + pygame-ce 环境运行；不使用游戏引擎。

## 暂不纳入

联网、存档、排行榜、多个可玩角色、多关卡、复杂剧情、完整弹幕脚本编辑器和大量素材动画。若课程要求有变化，再调整范围。
