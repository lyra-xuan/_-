# 功能需求与验收范围

## 项目目标

制作一款突出碰撞检测原理的单人 2D 弹幕射击游戏。使用 Python + pygame-ce，不依赖游戏引擎。运行效果要直观，便于演示命中区、擦弹区和扫掠检测。

## 当前已具备

- 玩家基础移动、低速移动、暂停和退出。
- 弹幕生成与 HUD 计数。
- AABB、圆-圆、线段-圆几何函数及空间网格。
- 玩家和子弹相对运动的扫掠碰撞。
- 两个碰撞回归测试。

## 建议的 V1 范围（待用户确认）

推荐做成“一关一 Boss”的短流程，而不是扩展成多关卡完整游戏：

1. 标题页：开始、操作说明、退出。
2. 单个可操作角色：移动、低速、自动射击。
3. 一个 Boss：两种清晰可辨的弹幕模式，包含阶段切换。
4. 碰撞反馈：命中、擦弹、无敌闪烁或短暂无敌、生命/分数显示。
5. 流程闭环：胜利、失败、重新开始。
6. 碰撞演示：可视化命中圆与擦弹圆；调试模式显示碰撞轨迹或网格候选。

这是控制工作量的建议，不代表所有功能已经实现。用户确认前，不扩展多角色、多关卡、道具或复杂剧情。

## 验收标准

- 可从标题页开始游戏，并能正常暂停、结束和重开。
- 玩家和 Boss 均能按窗口边界移动，操作响应稳定。
- 至少两种弹幕模式可观察到，并产生可复现的命中与擦弹。
- 擦弹只对每颗子弹计分一次；命中与擦弹不会混为一类。
- 高速移动和玩家移动时，扫掠碰撞能检测相对运动，不因单帧跨越漏判。
- 几何边界、相切、静止线段和网格边缘有自动化测试。
- 可在 Python 3.12 + pygame-ce 环境运行；不使用游戏引擎。

## 暂不纳入

联网、存档、排行榜、多个可玩角色、多关卡、复杂剧情、完整弹幕脚本编辑器和大量素材动画。若课程要求有变化，再调整范围。
