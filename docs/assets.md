# 美术与音效素材需求

## 已选方向

用户已选择**东方幻想乡原作风格方向**。战斗中的玩家、Boss 和弹幕先用 pygame 程序绘图验证玩法；标题页可以使用用户确认已获许可的现成图片素材。

## 原作素材与音乐

“非商业”本身不等于可以直接提取和使用原作游戏资源。东方Project使用规定案的公开整理文本注明，二次创作中禁止直接使用原作游戏的图像素材、音乐、文本和程序。本项目用户已确认标题页选用图片的许可覆盖本项目使用；当前实际纳入的图片和来源记录在 `assets/title/ATTRIBUTION.md`。本次没有加入原作音乐。

规则参考：[东方Project使用规定案（含原作素材使用条款）](https://thbwiki.cc/东方Project使用规定案)。这不是法律意见；使用素材时按已确认的许可范围执行并保留来源信息。

当前素材策略：标题页直接展示已获许可的素材图；战斗素材暂时继续程序绘制。新增素材须在 `assets/` 下登记来源、作者和许可范围。

## 最小素材清单

| 素材 | 建议规格 | 优先级 | 备注 |
|---|---:|---|---|
| 玩家机体 | 64×64 PNG，透明背景；可选 2-4 帧 | 必需 | 正面/俯视轮廓清楚，中心区域留出命中点 |
| Boss | 192×192 PNG，透明背景；可选 2-4 帧 | 必需 | 与玩家颜色、轮廓明显区分 |
| 圆形弹幕 | 16×16 或 24×24 PNG | 必需 | 至少两种颜色，用于区分弹幕模式 |
| 针形/椭圆弹幕 | 24×12 或 16×24 PNG | 可选 | 仅在第二种弹幕模式确实需要时制作 |
| 背景 | 480×640 PNG，或可纵向平铺图 | 必需 | 主体低对比，不能干扰弹幕辨识 |
| 命中/擦弹特效 | 64×64 PNG，2-4 帧 | 可选 | 可先用程序绘制圆环和闪光替代 |
| 标题/胜负界面装饰 | 480×640 PNG 或透明装饰层 | 可选 | 标题页已使用授权图片素材 |
| 音效 | OGG/WAV，短音效 | 可选 | 发射、命中、擦弹、Boss 阶段切换 |
| 背景音乐 | OGG，循环段 | 可选 | 最后制作或选用许可清楚的素材 |

## 提供素材时请附带

- 文件名和预期用途。
- 是否可裁切、变色、加特效。
- 原作者/来源链接和许可；自行绘制可注明“原创”。
- 若是参考图，标注只参考配色、构图还是整体风格。
