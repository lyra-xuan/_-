# 美术与音效素材需求

## 已选方向

用户已选择**东方幻想乡原作风格方向**，并决定先使用 pygame 程序绘图验证玩法。视觉上可参考东方弹幕的节奏、幻想氛围和高辨识度弹幕，但项目内的角色、立绘、弹幕图案、UI 和背景优先原创。

## 原作素材与音乐

“非商业”本身不等于可以直接提取和使用原作游戏资源。东方Project使用规定案的公开整理文本注明，二次创作中禁止直接使用原作游戏的图像素材、音乐、文本和程序。用户计划提供授权材料；收到并核对具体许可范围前，不把原作游戏素材或 ZUN 原曲加入游戏或仓库。

规则参考：[东方Project使用规定案（含原作素材使用条款）](https://thbwiki.cc/东方Project使用规定案)。这不是法律意见；若你能提供明确的许可或授权来源，我们再按许可范围核对。

当前安全方案：先用程序绘图；后续素材采用原创、明确授权或许可允许游戏内使用的资源。音乐先不加入，后续可用原创曲或明确允许嵌入游戏及公开仓库的曲目。

## 最小素材清单

| 素材 | 建议规格 | 优先级 | 备注 |
|---|---:|---|---|
| 玩家机体 | 64×64 PNG，透明背景；可选 2-4 帧 | 必需 | 正面/俯视轮廓清楚，中心区域留出命中点 |
| Boss | 192×192 PNG，透明背景；可选 2-4 帧 | 必需 | 与玩家颜色、轮廓明显区分 |
| 圆形弹幕 | 16×16 或 24×24 PNG | 必需 | 至少两种颜色，用于区分弹幕模式 |
| 针形/椭圆弹幕 | 24×12 或 16×24 PNG | 可选 | 仅在第二种弹幕模式确实需要时制作 |
| 背景 | 480×640 PNG，或可纵向平铺图 | 必需 | 主体低对比，不能干扰弹幕辨识 |
| 命中/擦弹特效 | 64×64 PNG，2-4 帧 | 可选 | 可先用程序绘制圆环和闪光替代 |
| 标题/胜负界面装饰 | 480×640 PNG 或透明装饰层 | 可选 | 确定菜单方案后再制作 |
| 音效 | OGG/WAV，短音效 | 可选 | 发射、命中、擦弹、Boss 阶段切换 |
| 背景音乐 | OGG，循环段 | 可选 | 最后制作或选用许可清楚的素材 |

## 暂定素材目录

```text
assets/
  player/
  boss/
  bullets/
  backgrounds/
  effects/
  audio/
  ATTRIBUTION.md
```

## 提供素材时请附带

- 文件名和预期用途。
- 是否可裁切、变色、加特效。
- 原作者/来源链接和许可；自行绘制可注明“原创”。
- 若是参考图，标注只参考配色、构图还是整体风格。

## 当前策略

先用 pygame 基础绘图形状实现玩家、Boss、弹幕和命中/擦弹效果，不先制作或引入成套图片。这样可以先验证玩法与碰撞表现，减少返工。确认资源来源和许可后，再补充 `assets/ATTRIBUTION.md`。
