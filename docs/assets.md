# 美术与音效素材需求

## 风格选择

玩法建议为原创单人弹幕射击，视觉方向任选：

- **A. 星象幻想（推荐）**：深色夜空、月相/星轨、青蓝与金色弹幕；可保留东方幻想气质，但角色、符号和弹幕图案原创。
- **B. 霓虹科幻**：深色太空、几何飞船、青紫色弹幕与扫描线。
- **C. 像素街机**：低分辨率像素角色、有限色板、复古 HUD。
- **D. 自定义**：给我 3-5 个关键词或一张参考图，并说明哪些元素不能照搬。

## 最小素材清单

| 素材 | 建议规格 | 优先级 | 备注 |
|---|---:|---|---|
| 玩家机体 | 64×64 PNG，透明背景；可选 2-4 帧 | 必需 | 正面/俯视轮廓清楚，中心区域留出命中点 |
| Boss | 192×192 PNG，透明背景；可选 2-4 帧 | 必需 | 与玩家颜色、轮廓明显区分 |
| 圆形弹幕 | 16×16 或 24×24 PNG | 必需 | 至少两种颜色，用于区分弹幕模式 |
| 针形/椭圆弹幕 | 24×12 或 16×24 PNG | 可选 | 仅在第二种弹幕模式确实需要时制作 |
| 背景 | 480×640 PNG，或可纵向平铺图 | 必需 | 主体低对比，不能干扰弹幕辨识 |
| 命中/擦弹特效 | 64×64 PNG，2-4 帧 | 可选 | 可先用程序绘制圆环和闪光替代 |
| 标题/胜负界面装饰 | 480×640 PNG 或透明装饰层 | 可选 | 确定菜单方案后再制作 |
| 音效 | OGG/WAV，短音效 | 可选 | 发射、命中、擦弹、Boss 阶段切换 |
| 背景音乐 | OGG，循环段 | 可选 | 最后制作或选用许可清楚的素材 |

## 提供素材时请附带

- 文件名和预期用途。
- 是否可裁切、变色、加特效。
- 原作者/来源链接和许可；自行绘制可注明“原创”。
- 若是参考图，标注只参考配色、构图还是整体风格。

在风格确认前，游戏继续使用 pygame 基础绘图形状，不先制作或引入成套图片。这样可以先验证玩法与碰撞表现，减少返工。
