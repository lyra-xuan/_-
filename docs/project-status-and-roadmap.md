## 项目目标

- 使用 Python + pygame-ce 制作单人 2D 弹幕射击游戏，不使用成熟游戏引擎。
- 采用三关推进的流程（杂兵波次 → 中 Boss → 关底 Boss + 符卡 → 关卡结算），玩法与术语参考东方红魔乡，突出碰撞检测的实现与可视化演示。
- 视觉与术语参考东方 Project；本项目是课程演示版，不追求逐帧复刻 TH06。
- 当前工作目录：`my-game`；参考工程：同级目录 `project-striker`。

## 已完成内容

### 可玩流程

- 标题页可进入游戏、打开三页说明书或退出。
- 三关依次推进：每关为过场 → 立绘对话 → 杂兵波次 → 中 Boss → 关底 Boss → 关卡结算；第三关无中 Boss。
- 玩家可移动、低速移动、连续射击和释放灵击；火力成长后弹数增加。
- 符卡由 `SpellCard` 数据描述，同一张符卡内的多个发射器各有独立冷却；限时耗尽或生命分段走完即切换下一张。
- 玩家有三条命；受击后清屏、重生并获得短暂无敌时间。
- 杂兵按编队入场、可悬停开火，被击破后掉落道具；Boss 换符卡时也会掉落道具。
- 支持胜利战绩、后记、鸣谢；失败可重开或返回标题。
- 最高分以 `hiscore.txt` 保存，胜利与失败两条路径都会在本局结束时检查。

### 碰撞检测与测试

- `src/collision.py`：AABB、圆-圆、点-圆、线段-圆检测和 `SpatialGrid`。
- 玩家与敌弹使用相对运动扫掠检测；擦弹和致命命中使用不同判定半径。
- 玩家弹与 Boss/妖精的碰撞也考虑双方位移。
- 测试覆盖几何边界、实体、碰撞扫掠、关卡状态机、Boss 与符卡结算、灵击、道具、装饰、美术和音频降级。

### 主要入口

- `src/game.py`：游戏状态、输入、战斗、碰撞、道具、计分和 UI。
- `src/director.py`：关卡推进状态机，不持有 pygame 资源，可脱离窗口单测。
- `src/stages.py` / `src/waves.py`：三关剧本、步骤数据与杂兵编队。
- `src/spells.py`：发射器、符卡与 Boss 定义。
- `src/dialogue.py`：立绘对话场景与逐字对话框。
- `src/entities.py`：玩家、敌弹、玩家弹、Boss、杂兵和道具实体。
- `src/config.py`：窗口、速度、判定、弹幕、计分和道具参数。
- `src/audio.py`：音效和场景 BGM 加载，失败时静默降级。

## 尚缺的验收环节

### 人工完整流程验收（唯一的阻塞项）

自动化测试与 headless 冒烟不能替代画面、按键与音频的实际验收。建议使用 Python 3.12 环境，按 README 启动后完成以下检查：

- 标题进入、说明书翻页、返回标题。
- 第一关开场卡与立绘对话翻页；移动、低速、射击、灵击、暂停/继续。
- 三关各自的杂兵波次、中 Boss 与关底 Boss 能否正常登场与击破。
- F2 调试层、F3 无敌切换和 HUD 状态（含灵击余量）。
- 命中/擦弹、道具磁吸与回收线、符卡切换与超时、取得奖励与失败提示。
- 失败后重开/返回标题；胜利后战绩、后记、鸣谢翻页与四个场景的 BGM 切换。

建议将人工检查日期、环境和结果补充在本文件末尾或项目验收记录中。

## 有意保留的简化

以下行为与原作不同，属于本项目的主动简化，不计为缺陷：

- 第三关没有中 Boss，直接进入关底 Boss。
- 最后一张符卡超时按「Boss 被击破」处理，而非原作中另行判定。
- 只有一名可玩角色，没有机体与射击类型选择。
- 关卡步骤为手写数据，没有外部脚本编辑器。

## 与 project-striker 的定位差异

`project-striker` 是更完整的 STG 参考工程，包含多个机体/射击配置、Replay 和更丰富的结算系统。当前项目保持单角色范围，把课程核心放在碰撞算法、扫掠检测和调试展示上；虽然在关卡数与流程结构上已向原作靠拢，但不以完整 STG 系统为目标。
